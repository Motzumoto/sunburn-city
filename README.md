SUNBURN CITY is a top-down crime game set in 1986 Costa Vela, a sun-bleached coastal metropolis where a small-time operator gets tangled in jobs that are bigger than they look. Explore on foot, take a car, drive through generated traffic and crowds, drift, and use a stylized pistol; the four deterministic screenshot scenes are staged from the same live entities and renderer. WASD or arrows move and drive, the mouse aims and fires, E enters or exits the nearest car, Space handbrakes into a drift, and Esc pauses.

## Run it

```sh
node serve.ts
```
