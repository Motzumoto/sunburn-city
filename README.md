SUNBURN CITY is an original top-down open-world crime game set in Costa Vela. Walk sun-bleached boulevards and the boardwalk, take vehicles, outrun a wanted level, and complete six jobs for a fixer. The facades, palms, street life and soundtrack are drawn or synthesized locally.

## Run it

From the repository root:

```sh
node serve.ts
```

Open `http://localhost:8080`. The `game/` directory can also be served directly as a static site. There is no build step or external asset dependency.

### Controls

- `WASD` / arrow keys: walk or drive; `Shift`: sprint.
- `E`: enter or leave a nearby vehicle; pay off heat at Sunspray.
- Mouse: aim and fire; `1`–`4`: select a weapon; `R`: reload.
- `Space`: melee; `Tab` / `M`: city map; `Esc`: pause.
- Mouse wheel: change radio station while driving.

### Screenshots

`shots.json` lists four deterministic scenes: `city`, `chase`, `mission`, and `heist`. They show South Beach at golden hour, Neon Row, Pier 9, and Vela Tower. Open one with `?shot=<name>&seed=1`.
